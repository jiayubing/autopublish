```text
desktop/main.js
  -> authenticated runtime + workspace-runtime
  -> desktop/composition/workspace-runtime-composition

  -> typed IPC registry + desktop/ipc/register.js
  -> desktop/preload.js allow-list

Publication writes: createOperationalStore -> OperationalStore internals
Publisher routing: desktop-publisher-router -> worker/media publishers
Content file writes: ContentStore / ArticleStore and lifecycle services

```

`desktop/main.js` owns process bootstrap, `workspace-runtime.js` owns one
workspace lifecycle, `workspace-runtime-composition.js` owns workspace service
composition, and `desktop/ipc/register.js` is the authenticated IPC registry
owner. The Renderer has no Node or infrastructure import path; it consumes the
preload API through domain bridge and feature modules. `verify-phase-08-gates`
protects dependency direction, OperationalStore internals, unique writers and
publisher ownership, 109 typed capabilities, retired-path absence, reviewed
module ceilings, generated-output absence, and package boundaries.
