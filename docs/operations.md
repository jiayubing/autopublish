# 配置、运行与排障

## 数据与配置

首次启动明确选择内容库。内容库可迁移，应用凭据、浏览器状态、日志和缓存不随业务目录混放；不要把运行数据放进安装包或仓库。环境覆盖应来自操作系统/启动环境，不从内容库 .env 隐式取得 AI 密钥。具体变量名与默认值以 [应用配置](../auto—publish/config)及[桌面组合入口](../auto—publish/desktop/composition)为准，不在多处复制完整清单。

设置中的 AI 提供方用于文章写作，使用 OpenAI-compatible Chat Completions。可填写 HTTP/HTTPS base URL 或完整 /chat/completions 地址；支持自定义端口和路径，不强加 /v1，只追加一次路径。地址禁止内嵌账号密码、查询参数与片段，API Key 单独保存。

“设置 → 豆包 GEO”用于知识研究，选择 Coding Plan 或标准方舟。准确地址由[共享端点定义](../auto—publish/src/domain/doubao-geo-endpoints.json)维护。新配置默认 Coding Plan，旧配置保留标准地址；标准地址可能另计费，系统不自动切换。保存仅写本机加密配置，不发请求。

测试连接和联网搜索是两项独立操作，每次各一条固定文本请求，会消耗接口用量；未保存配置不能测试，测试时不能保存或启动研究。Responses 可用不等于 web_search 或引用能力可用；失败不自动重试、切换地址。知识研究通常单次等待最多 2 分钟，K 成稿最多 10 分钟，期间可取消；延长等待不授权恢复先前不确定任务。

## 常见故障

- 配置/权限错误：确认实际选择的接口和模型能力，按安全错误码处理，不通过切到另一个收费接口绕过拒绝。
- 知识生成失败：保留旧正文，区分候选、未验证模型稿与没有收到结果。超时和断线不自动重发。
- 浏览器登录/验证：由用户在当前会话处理。检测异常不等于未登录，不能覆盖已有会话；账号身份变化须显式处理，不静默改绑。
- uncertain 投稿或订单：进入需处理事项核对真实远端结果，不直接重试。没有订单号不能伪造订单。
- 内容库损坏、未知版本或未知 owner 锁：停止猜测覆盖/回收，保留文件及安全诊断，由对应 store owner 调查。只在能证明旧进程已退出且身份匹配时按现有恢复路径处理。
- 删除恢复失败：使用既有本地修复路径；不要直接删除墓碑、日志或发布/订单证据来解锁文章。

## 发布候选

普通 CI 与完整候选入口以 [ci.yml](../.github/workflows/ci.yml)为准。手动 workflow_dispatch 的 release=true 才运行容量、容器、产物、解包导航、依赖审计和发布 evidence 等额外门禁；普通 push/PR 仍保留业务回归和安全检查。

[安装包入口](../.github/workflows/windows-installer.yml)仅手动执行，输入完整候选 SHA，checkout 后核对 SHA 再回归及构建。dist:alpha:dirty 生成未签名内部诊断包，不能冒充签名正式发布。生产打包命令的 clean source、manifest、签名及产物检查不能用旧构建结果代替；当前未完成验收见[剩余工作](work.md)。

执行迁移前备份，先对隔离副本 dry-run 和恢复验证；旧应用不保证可写升级后的内容库。不在真实内容库试错，不覆盖用户安装来测试升级。真实模型/登录/投稿/付费/图片上传、服务器和生产迁移需当次具体授权。

## 独立鉴权服务

本机测试不连接真实服务器。启动、环境、迁移、备份、账户管理、健康与代理信任配置统一见[auth-server README](../auto—publish/auth-server/README.md)。/healthz/live 只代表进程可响应，ready 执行轻量连接/schema 检查；完整性检查是独立操作。代理/TLS 真实拓扑验收见该服务的[人工验收说明](../auto—publish/auth-server/docs/proxy-source-manual-acceptance.md)。
