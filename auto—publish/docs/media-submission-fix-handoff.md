# 媒体投递修复接力说明

用于新开线程和新分支时直接接手修复。当前只做修复，不新增功能。

## 目标

把 `auto—publish` 里尚未闭合的媒体投递问题修好，让桌面端的预览、订单状态和页面文案都回到一致、可用、可读的状态。

## 已确认问题

1. 媒体队列里有 `previewArticle()` 的绑定，但每条卡片里没有真正的“预览”按钮。
2. 订单中心里“已发布”筛选失效，状态映射和筛选逻辑不一致。
3. 媒体相关页面仍有乱码，主要影响可读性。

## 修复顺序

1. 补齐媒体队列预览按钮。
2. 修正订单状态映射和筛选。
3. 清理媒体相关页面乱码文案。
4. 回归测试。
5. 记录结果和提交 hash。

## 执行要求

- 先读文档和相关代码，再动手。
- 每修一个小问题都要先审查，再测试，再验收，再提交。
- 保持修改最小，只修复当前问题，不扩展新功能。
- 不引入真实投递，也不改动密钥处理流程。
- git 提交信息必须使用中文。
