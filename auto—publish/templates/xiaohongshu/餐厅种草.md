# 小红书-餐厅种草 文案撰写要求

## 平台特性
- 种草导向短图文，字数 300-500 字
- 开头 3 秒定生死，情绪共鸣为王
- 视感想象优先，实用信息为辅

## 结构要求
1. 标题：15 字内，一个情绪钩子或反常识点
2. 开头：一句共鸣或惊叹
3. 正文：3-5 个推荐点，每点一两句，加 emoji 分隔
4. 结尾：一句互动引导 + 话题标签区

## 写作风格
- 口语化、有温度，像朋友安利
- emoji 适度使用（每段 1 个，不堆砌）
- 短句为主，每句不超过 20 字

## 话题标签
- 结尾加 5-8 个 # 标签
- 覆盖目的地、品类、场景
- 格式：#标签1 #标签2...

## 禁止
- 不写"本文由AI生成"等声明
- 不编造数据
- 不写长段落，超过 3 行就拆开
