# 模板C：吃法探店型

> 用途：推荐一种吃法或一家店，教读者怎么吃
> 适配场景：携程笔记、小红书探店笔记
> 核心武器：仪式感描写 + 必点清单 + 价格锚点
> 篇幅：短平快，信息密度高但总量小

---

## 标题公式

```
[品类]｜[价格锚点] + [情绪结论] + [好奇心钩子]
```

### 示例

- 淄博烧烤｜人均50吃撑！这才是撸串的正确打开方式
- 小饼烤炉加蘸料，淄博烧烤三件套！这趟为了吃专门来的淄博

### 标题关键词库

| 类型 | 词汇 |
|------|------|
| 价格锚点 | 人均50、人均XX吃撑 |
| 情绪结论 | 正确打开方式、灵魂暴击 |
| 好奇心 | 这才是、三件套、绝绝子 |

## 开头模式：亲测感受 + 一句话结论

### 结构

```
第一句：亲测判断（我替你试过了）
第二句：情绪表达（值不值）
第三句：引导正文（往下看）
```

### 示例

> 终于来打卡全网爆火的淄博烧烤了！亲测这波热度真的不是营销，一口饼卷肉直接香到跺脚👇

### 另一种开头：灵魂公式

> 烧烤夏日攻略：烟火气中的极致体验✨
> 盛夏的浪漫是什么？当然是撸串儿啊！🌆

### 吃法拆解示例

```
## 灵魂吃法：小饼+烤串+葱丝=碳水快乐天花板

1. **小饼打底**：把烤得焦香的小饼撕开，刷上一层甜面酱和辣酱
2. **撸串放料**：把烤好的五花、羊肉、板筋撸到饼上，撒上孜然和芝麻
3. **卷葱开炫**：放上几根鲜脆的葱丝，卷成春卷状，一口咬下，香、辣、鲜、脆在嘴里爆开！
```

### 必点清单示例

```
## 必点烤串清单

- **带皮五花肉**：焦香流油，肥而不腻，卷饼绝配！
- **金岭鲜羊肉**：现切现串，嫩到爆汁，撒上孜然香到舔手指
- **雪花松板肉**：脆弹有嚼劲，越嚼越香
- **网红烤面包**：刷满炼乳，外脆里软，甜口星人必点
- **烤青椒+玉米粒**：解腻神器，清甜爽口
```

### 小贴士示例

```
## 吃烧烤小Tips

1. **避开高峰**：饭点人超多，建议错峰前往或提前取号
2. **自己动手**：烤架是自动旋转的，不用自己翻，新手也能烤出焦香口感
3. **搭配饮品**：来一瓶当地的大窑汽水，解辣又解腻
4. **人均50+**：性价比拉满，吃到扶墙出
```

## 结尾：一句话总结 + 标签

### 结尾示例

- "淄博烧烤的快乐，只有亲自来尝才懂！小饼卷肉的仪式感，烟火气十足的氛围，绝对值得专门跑一趟。"
- "这座城市用烧烤架当画布，画出山东最生猛的江湖气——趁暑假尾巴，快冲！"

### 标签策略

同A/B类：地域品类 + 场景 + 泛流量，2-5个标签。

## 语言特征备忘

| 特征 | 说明 |
|------|------|
| 感官描写 | 焦香流油、滋啦炸开、嫩到爆汁、香到跺脚 |
| 仪式感 | 强调动手过程，自己烤、自己卷、自己撸 |
| 短句密集 | 一句一个信息点，不废话 |
| emoji | 每段开头或关键句用emoji，降低疲劳 |
| 加粗菜名 | 必点清单每项菜名加粗，方便扫读 |
| 价格锚点 | 人均XX吃撑，给出明确心理预期 |

## 可信度构建

C类主要靠三层：
1. **亲测背书**："亲测""实测""亲自来尝"
2. **细节背书**：具体价格、具体菜名、具体步骤
3. **情绪真诚**：用真实感受代替专业术语，"香到跺脚"比"味道不错"有说服力

---

## C类适用边界

- 适合推荐一种吃法、一家店、或一次探店体验
- 不适合做多店横评（那是A类的活）
- 不适合做行程规划（那是B类的活）
- 核心是"教你怎么吃"，不是"帮你选哪一家"
