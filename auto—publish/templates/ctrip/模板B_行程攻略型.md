# 模板B：行程攻略型

> 用途：帮读者安排某个城市几天的行程，覆盖吃住行游
> 适配场景：携程笔记、小红书旅游攻略
> 核心武器：路线合理性 + 体验感描写 + 实用信息密度

---

## 标题公式

```
[地域/品类] + [时间跨度] + [定位词] + [情绪词]
```

### 示例

- 淄博烧烤绝绝子！2天1夜保姆级攻略🔥
- 从"烧烤顶流"到"文化烟火"，解锁鲁C的万种风情
- 小饼烤炉加蘸料，淄博烧烤三件套！这趟为了吃专门来的淄博

### 标题关键词库

| 类型 | 词汇 |
|------|------|
| 体验感 | 保姆级、绝绝子、专门来、解锁 |
| 时间 | 2天1夜、1-3天、周末 |
| 情绪 | 灵魂暴击、烟火气、松弛感 |

---

## 开头模式：场景画面 + 情绪共鸣

### 结构

```
第一句：场景画面（把你拉进去）
第二句：情绪共鸣（你也有这种感觉对吧）
第三句：引出攻略（跟我走）
```

### 示例

> 盛夏的浪漫是什么？当然是撸串儿啊！🌆 夕阳西下，微风习习，围坐在小炉旁，自己动手烤制滋滋冒油的肉串...淄博这座因烧烤火爆出圈的城市，用最地道的烟火气征服着每一个吃货的胃！这篇保姆级攻略带你玩转淄博，吃最正宗的烧烤，感受最local的人文！💯

### 另一种开头：趋势判断 + 深度定位

> 2023年，淄博烧烤以"小饼烤炉加蘸料"的灵魂公式火遍全网；2025年，这座"齐国故都"依然保持着"烟火气与文化感并存"的本色。以下从爆火核心、行程规划、美食地图到避坑指南，为你整理一份"保姆级"淄博旅行攻略。

---

## 正文结构：按时间线组织

### 固定模板

```
## Day1 [主题名]

**上午**：
- [时间] [动作/抵达]→[地点]（[地址]）
- [时间] [活动]（[开放时间/备注]）
- [一句话推荐理由]

**中午**：
[第一顿推荐，给具体店名和菜品]

**下午**：
- [时间] [地点]（[地址]）
- [一句话推荐理由]

**傍晚/晚上**：
[重头戏，通常是最核心的体验]
必打卡：
1. [店名]（[地址]）
2. [店名]（[地址]）
点单tips：[核心推荐搭配]

## Day2 [主题名]

**上午**：
[同上格式]

**中午**：
[必吃清单，列2-3项]

**下午**：
[同上格式]

**返程**
```

### 进阶版：多时长适配

给1日/2日/3日三个版本，适配不同时间预算的读者：

```
### 1日游（紧凑版）：[主题]"速览"
上午：[路线] → 午餐（[推荐]）；
下午：[路线] → [活动]；
晚上：[核心体验] → 返程。

### 2日游（深度版）：[主题]"全体验"
[同上标准Day1/Day2格式]

### 3日游（休闲版）：慢游[城市]"不赶场"
Day1：[主题日]→ 具体安排
Day2：[主题日]→ 具体安排
Day3：[自然休闲日]→ 具体安排
```

### 时间安排细节技巧

- 每个时间点用emoji标记：☀️上午 🏛下午 🌆傍晚 🌃晚上
- 地点用📍，时间用⏰，酒店用🏨，餐饮用🥗
- 给具体地址（区和路名），不只是景点名
- 标注开放时间、闭馆日
- 一句话点评穿插，不干巴巴列行程

## 穿插专题板块（B类加分项）

行程主线外，穿插1-3个知识/实用板块，增加信息密度和深度感：

### 可选板块

1. **小课堂/秘诀**：教读者某种技能或知识
```
### 【烧烤小课堂】🍢
1️⃣ 烤制秘诀：七分熟刷酱，翻烤要勤快！
2️⃣ 正确吃法：小饼+肉+葱+酱=淄博灵魂吃法！
3️⃣ 隐藏菜单：烤面包片蘸炼乳，惊喜值MAX！
```

2. **爆火密码/文化解读**：解释为什么这个地方值得去
```
## 一、淄博的"爆火密码"：烧烤+文化，双引擎驱动
[2-3段分析，从社会心理 + 历史文化两个角度解读]
```

3. **美食地图/必吃清单**：独立的美食推荐板块
```
### 必吃清单
1. [菜名]
2. [菜名]
3. [菜名]
```

4. **更多玩法/备选景点**：给时间充裕的读者更多选择
```
### 【更多玩法】🌈
📍[景点名]（[地址]）
📍[景点名]（[地址]）
```

## 实用信息版块（B类标配）

行程完后，单独出一个实用信息板块：

```
## 【实用信息】💡

### 交通
- 飞机：[最近机场 + 转乘方式]
- 高铁：[站点 + 耗时]
- 市内：公交/打车/单车

### 住宿推荐
- [区域]（首选）：[理由]
  - 高性价比：[酒店名]
  - 特色民宿：[民宿名]

### 避坑指南
- [排队建议]
- [避坑提醒]
- [隐藏福利]
```

### 实用信息示例

```
### 交通
外部到达：
- 高铁：淄博北站（京沪高铁），济南→淄博约30分钟，票价24元
- 飞机：最近机场济南遥墙国际机场，距淄博约1.5小时车程

市内交通：
- 公交：票价2元，覆盖主要景点（如136路到周村古商城）
- 打车：起步价7元，市区内景点间10-20元
```

## 结尾：一句话升华 + 标签

### 升华句示例

- "这个夏天，跟着这份攻略玩转淄博！从早吃到晚，感受最地道的烟火气～"
- "淄博的温度，是炭火燎出的星辰，是小饼裹住的人间。"
- "这座城市用烧烤架当画布，画出山东最生猛的江湖气"

### 标签策略

同A类：地域品类 + 场景 + 泛流量，2-5个标签。

## 语言特征备忘

| 特征 | 说明 |
|------|------|
| emoji密度高 | 用emoji做时间/地点/活动标记，降低阅读疲劳 |
| 短句节奏 | 大量短句+句号，制造轻松感 |
| 画面感 | "油花滋啦炸开""万人举杯烟火升腾" |
| 场景词 | 烟火气、松弛感、江湖气、神仙吃法 |
| 人称 | 第一人称"我" + "你"拉近距离 |

---

## 可信度构建

B类主要靠三层：
1. **身份背书**："作为淄博土著""亲测""跑了好多趟"
2. **细节背书**：具体时间、地址、价格、公交线路
3. **实用反差**："避开高峰""提前2小时取号""非网红店18点直接吃"
