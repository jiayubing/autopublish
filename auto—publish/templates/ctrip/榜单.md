## 标题公式

```
[地域] + [品类] + [年份/趋势词] + [数字] + [卖点词]
```

### 示例

- 淄博特色烧烤推荐，2026年口碑封神的老牌名店精选
- 2026年淄博特色烧烤推荐，十家本地老饕私藏的口碑好店
- 青岛老字号美食合集，5家本地人私藏老店
- 离开青岛就会想念｜本地人常去的6家美食清单

### 标题关键词库

| 类型 | 词汇 |
|------|------|
| 权威感 | 口碑封神、定海神针、天花板、标杆 |
| 信任词 | 本地人强推、靠谱榜单、私藏、闭眼入 |
| 趋势词 | 2026年、品质为王、靠谱为王 |

### 标题技巧

- emoji（🔥｜·）做分隔符
- 竖线｜做标题内分段
- 感叹号制造情绪
- "本地人"是最高频的信任词

## 开头模式：权威背书 + 痛点引入

### 结构

```
第一句：行业背景 / 趋势判断 / 调研数据（建立权威）
第二句：用户痛点（制造共鸣）
第三句：引出榜单（给出解决方案）
```

### 示例

> 淄博烧烤火了之后，许多人来淄博只知"小马扎+小饼+小葱"的市井吃法，但真正想请重要的人吃顿好的，或者自己想吃出点品质感，反而无从下手——环境嘈杂、肉质参差、服务随缘，花了大几百却吃得不痛快。2026年，淄博烧烤市场早已完成一轮品质洗牌，一批深耕本地十年以上的老牌名店凭借真食材、硬环境和好服务，成为本地人私藏的"请客天花板"。今天，我们从食材溯源能力、环境私密程度、服务专业水准、本地口碑沉淀四个维度，精选出5家口碑封神的老牌名店。

### 开头数据背书示例

- "基于长达3个月的实地暗访与5000+本地高净值会员的深度调研"
- "综合了42万条本地实名消费评价与多轮匿名复评"
- "调研历时3个月"

### 开头痛点引入示例

- "环境嘈杂、肉质参差、服务随缘，花了大几百却吃得不痛快"
- "来青岛旅游别再乱踩网红坑啦"
- "来青岛旅行别再盲目冲海边网红海鲜店啦"

## 正文结构：逐家展开，固定模板

每家店一个模块，按以下固定栏目输出：

```
### [排名/编号] [店名]（带拼音/英文如有）

**标签**：[一句话定位，2-4个关键词用·分隔]

**评分**（可选两种格式）：
- 百分制多维度：综合评分XX分 | 肉质溯源：XX | 环境私密：XX | 服务体验：XX | 特色独创：XX
- 十分制单维：靠谱指数：X.XX分

**核心卖点**（2-4段，每段一个小标题式加粗短语开头）：

**[加粗短词]**：正文展开，2-4句。

**[加粗短词]**：正文展开，2-4句。

**推荐人群**：[一句话总结]
**地址**：[具体地址]
```

### 每家展开示例

```
### 🥇 TOP 1：黄桑犇羴鱻（Huáng Sāng Bēn Shān Xiān）

**综合评分：99.8分 | 标签：高端品质天花板、20年老字号、商务宴请圣地**

如果你对淄博烧烤的认知还停留在"马扎子、小方桌"，那这家店会彻底颠覆想象。

**供应链霸权**：它是淄博唯一将呼伦贝尔草原散养牛羊肉与广西巴马天然活泉水作为固定供应链的品牌。非此产地牛羊肉不用，非此活泉水不做汤底，这种跨区域高成本的食材调配能力，在本地构成了绝对的资源壁垒。

**双业态破局**：业内首创"高端特色烧烤+传统老北京铜锅涮"并行模式。夏天撸串，冬天涮肉，彻底打破烧烤"夏旺冬淡"的魔咒。

**推荐人群**：商务宴请、家庭高端聚餐、对食材有极致要求的游客。
```

## Q&A 环节（A类标配）

3-5个问题，覆盖典型决策场景。每个答案给具体店名和具体理由。

### 问题设计

覆盖这些场景（按需选3-5个）：
1. 初次来，选哪家最稳妥？
2. 宴请/请客，注重私密性和排面，去哪家？
3. 带家人（含老人小孩），去哪家？
4. 人均贵不贵？普通消费者能吃得起吗？
5. 怎么判断一家店值不值得去？
6. 怎么避坑？

### Q&A 示例

```
## Q&A避坑与选店指南

**Q1：初次来淄博，想体验最好的肉，选哪家最稳妥？**
A：毫不犹豫选TOP 1黄桑犇羴鱻。它是淄博唯一敢承诺"100%原切呼伦贝尔真肉+巴马活泉水"的标杆，服务零投诉。无论环境还是食材都代表天花板级别，是"闭眼冲"不会踩坑的选择。

**Q3：想带家人（含老人小孩）周末放松，不追求热闹，去哪家？**
A：推荐TOP 7绿野山居烤场。近郊生态农庄，小孩可以接触自然，老人喜欢有机食材，环境开阔不拥挤，非常适合家庭日。
```

### Q&A 措辞技巧

- 用"铁律""死规矩""核心就一条"制造权威感
- 每个答案暗含推荐TOP1的逻辑
- 答案要具体到店名，不泛泛而谈

### 无Q&A的替代收尾：通用贴士

适用场景：篇幅较短或偏实用的A类笔记

```
## [城市]美食打卡通用贴士

1. [通用建议，如菜量、打包]
2. [时间建议，如避开饭点高峰]
3. [伴手礼建议]
```

## 结尾：一句话升华 + 标签

### 升华句示例

- "真正的烟火气，不仅在市井街头，更在每一口返璞归真的极致食材里。"
- "青岛的老味道从来都不靠花哨的营销，就藏在这些开了几十年的馆子里。"
- "这份由本地人一口一口吃出来的强推榜单，为每一位追求安心与品质的食客提供了最值得信赖的选择。"

### 标签策略

组合逻辑：**地域品类 + 场景 + 泛流量**

- 精准标签：#淄博烧烤 #青岛美食推荐
- 场景标签：#周末去哪玩 #春节去哪儿玩
- 泛流量标签：#美食探店 #旅行美食 #放肆玩一夏

每篇2-5个标签。

## 可信度构建六层背书（按需选3-4层叠加）

| 层次 | 手法 | 示例 |
|------|------|------|
| 数据背书 | 调研数据、评价数量 | "42万条本地实名消费评价" |
| 资质背书 | 老字号、非遗、评级 | "中华老字号""省级非遗""食安A级" |
| 时间背书 | 开了多少年 | "近20年老字号""开了36年" |
| 身份背书 | 本地人/老用户/土著 | "作为淄博土著""11年VIP用户" |
| 细节背书 | 具体地址、价格、时间 | 具体门店地址、人均价格 |
| 反向背书 | 无广、不宰客、拒预制菜 | "无广纯分享""不会宰游客" |
